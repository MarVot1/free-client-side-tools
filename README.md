## 🌟 Overview

[**LocalToolDeck**](https://localtooldeck.com) is an open-source suite of **115 browser-native micro-applications** engineered to replace bloated, ad-ridden web converters and privacy-invasive online utilities. 

Every single computation—whether parsing multi-megabyte PDFs, encrypting files via AES-GCM 256-bit, cropping US passport photos, or simulating complex 30-year mortgage amortizations—runs **100% locally in the browser runtime** utilizing modern WebAssembly (Wasm), HTML5 Canvas, Web Audio, and Web Crypto APIs.

### 🛡️ Core Architectural Principles

- **🔒 Zero-Knowledge Privacy:** No backend server processes your data. Files, photos, documents, and calculation parameters never leave your local device.
- **⚡ Zero-Latency Performance:** Pre-rendered with Astro 5 SSG and distributed globally across Cloudflare's Edge network (643 static pages total). Perfect 100/100 Core Web Vitals.
- **⚡ Instant Access:** No accounts, no subscriptions, and no multi-step wizards. Every utility is ready to use immediately.
- **📱 Responsive & Accessible:** Dark/light mode support, mobile-first layouts, and high-contrast accessibility across iOS, Android, macOS, and Windows.
